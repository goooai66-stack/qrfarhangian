# فید نرخ بازار

اپ به هیچ API شخص ثالثی وابسته نیست. فقط یک فایل JSON کوچک را با یک درخواست GET می‌خواند.
در این درخواست هیچ داده‌ای از کاربر فرستاده نمی‌شود. آدرس فید هنگام بیلد تعیین می‌شود:

```bash
./gradlew :app:assembleRelease -Phesabyar.ratesUrl=https://example.com/rates.json
# یا یک‌بار در ~/.gradle/gradle.properties:  hesabyar.ratesUrl=https://…
```

اگر آدرسی تنظیم نشود، اپ کاملاً آفلاین کار می‌کند و کاربر نرخ روز را با دکمه‌ی ✎ در تب ابزارها دستی ثبت می‌کند.
فقط آدرس `https://` پذیرفته می‌شود.

## قالب

نمونه: [`tools/rates-feed/rates.sample.json`](../tools/rates-feed/rates.sample.json)

| فیلد | توضیح |
|---|---|
| `updatedAt` | زمان یونیکس (ثانیه) آخرین به‌روزرسانی قیمت‌ها |
| `source` | نام کوتاه منبع (حداکثر ۴۰ نویسه) |
| `rates.<KEY>.price` | عدد صحیح مثبت |
| `rates.<KEY>.unit` | `"rial"` (پیش‌فرض) یا `"toman"` |
| `rates.<KEY>.change` | درصد تغییر روزانه (اختیاری) |

کلیدها: `GOLD_18K_GRAM` (یک گرم طلای ۱۸ عیار)، `COIN_EMAMI`، `COIN_HALF`، `COIN_QUARTER`، `USD`، `USDT`.
کلید ناشناخته نادیده گرفته می‌شود و هر کلید اختیاری است.

## ایمنی داده

* هر قیمت پیش از ذخیره از `RateSanity` می‌گذرد: قیمت صفر یا منفی، یا جهش بیش از ۴۰٪ نسبت به قیمت قبلی رد می‌شود.
  جهش ۴۰٪ معمولاً از اشتباه ریال/تومان می‌آید. در این حالت آخرین قیمت سالم باقی می‌ماند و کاربر پیام «نرخ غیرعادی» می‌بیند.
* درخواست به‌روزرسانی فقط وقتی اپ باز است فرستاده می‌شود و حداکثر هر ۳۰ دقیقه یک بار. کار پس‌زمینه‌ای وجود ندارد.
* نرخ‌هایی که بیش از ۶ ساعت از دریافتشان گذشته با برچسب «قدیمی» نمایش داده می‌شوند.

## میزبانی پیشنهادی (بدون سرور)

یک اسکریپت زمان‌بندی‌شده‌ی شخصی، مثلاً GitHub Actions با cron هر ۱۵ دقیقه یا یک Cloudflare Worker، قیمت‌ها را از منبعی که
**مجوز استفاده‌اش را دارید** می‌گیرد و همین JSON را روی GitHub Pages یا R2 منتشر می‌کند. هزینه‌ی این روش عملاً صفر است و
هزاران کاربر فقط یک فایل ایستا را می‌خوانند. منبع قیمت را عمداً در این مخزن قرار ندادم: بیشتر سایت‌های قیمت ایرانی
استفاده‌ی خودکار را در شرایط استفاده‌شان محدود کرده‌اند و انتخاب منبع مجاز با خود شماست.
