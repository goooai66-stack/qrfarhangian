## ۲. ساخت

```bash
# هر Flavor جدا؛ split-per-abi حجم هر APK را نصف می‌کند.
flutter build apk --release --flavor bazaar --split-per-abi --obfuscate \
  --split-debug-info=build/symbols/bazaar \
  --dart-define=API_BASE_URL=https://api.YOUR-DOMAIN.ir

flutter build apk --release --flavor myket --split-per-abi --obfuscate \
  --split-debug-info=build/symbols/myket \
  --dart-define=API_BASE_URL=https://api.YOUR-DOMAIN.ir
```

- خروجی: `build/app/outputs/flutter-apk/app-armeabi-v7a-bazaar-release.apk` و `arm64-v8a` و `x86_64`. به فروشگاه هر سه را بده (هر دو فروشگاه چند APK را می‌پذیرند)، یا اگر فقط یک فایل ممکن بود، arm64.
- پوشه‌ی `build/symbols/*` را نگه دار تا گزارش کرش‌ها قابل خواندن باشد.
- **حجم** (معیار: زیر ۲۵ مگابایت هر APK):
  ```bash
  ls -lh build/app/outputs/flutter-apk/*.apk
  flutter build apk --release --flavor bazaar --target-platform android-arm64 --analyze-size
  ```
  آنچه حجم را پایین نگه می‌دارد:
  - minify و shrinkResources روشن است.
  - آیکون‌های Material خودکار tree-shake می‌شوند.
  - فقط سه وزن فونت Vazirmatn (۳۶۰KB).
  - داده‌ی غذا ۱۶KB است.
  - تصویر یا Lottie سنگین نداریم.
- **شروع سرد** (معیار: زیر ۲ ثانیه روی گوشی ارزان): قبل از `runApp` فقط یک کوئری سبک SQLite اجرا می‌شود. همه‌ی کارهای دیگر بعد از اولین فریم انجام می‌شوند: آنالیتیکس، ویجت، یادآورها و سهمیه. اندازه‌گیری:
  ```bash
  adb shell am force-stop ir.calorielens.app
  adb shell am start -W -n ir.calorielens.app/.MainActivity   # TotalTime
  ```

## ۳. صفحه‌ی فروشگاه (ASO)

**عنوان:** کالری‌لنز | کالری شمار با عکس، رژیم لاغری

**توضیح کوتاه** (تا ۸۰ نویسه):
> از غذات عکس بگیر، کالری‌اش رو بگیر! کالری شمار هوشمند با غذاهای ایرانی

**توضیح بلند** (پیش‌نویس؛ کلیدواژه‌ها پررنگ):

> **کالری‌لنز** یک **کالری شمار** هوشمند برای **غذاهای ایرانی** است. کافی است از بشقابت عکس بگیری تا **هوش مصنوعی** غذا و مقدارش را تشخیص دهد و **کالری غذا** را حساب کند.
>
> 🍛 **شمارش کالری با عکس**: چلوکباب، قورمه‌سبزی، ته‌دیگ، کشک بادمجان و ده‌ها غذای ایرانی را می‌شناسد.
> 🥄 **واحدهای خودمانی**: کفگیر، ملاقه، کف دست، لیوان، و نه فقط گرم.
> 🎯 **برنامه غذایی شخصی**: بر اساس سن، قد، وزن و هدفت (**کاهش وزن**، ثابت ماندن یا افزایش وزن)، کالری و درشت‌مغذی‌های روزانه را حساب می‌کند و تاریخ رسیدن به هدف را نشان می‌دهد.
> 🎙️ **ثبت صوتی**: بگو «یه کفگیر برنج با قیمه خوردم»، خودش ثبت می‌کند.
> 📈 **نمودار پیشرفت**: وزن، کالری هفتگی، روزهای پیاپی و نشان‌ها.
> 💧 آب، یادآور وعده‌ها، حالت **رمضان** (سحری و افطار)، ویجت صفحه‌ی اصلی.
> 🔒 داده‌هایت روی گوشی خودت است. عکس‌های قبل و بعد هرگز آپلود نمی‌شوند.
>
> مناسب برای **رژیم لاغری**، **رژیم غذایی** سالم و **تناسب اندام**.
>
> ⚠️ کالری‌لنز جایگزین پزشک یا متخصص تغذیه نیست. اعداد تخمینی‌اند.

- [ ] **دسته‌بندی:** سلامت و تناسب اندام (یا سبک زندگی)
- [ ] **رده‌ی سنی:** ۱۲+ یا معادلش (زیر ۱۸ سال هدف کاهش وزن غیرفعال است؛ تبلیغات در نسخه‌ی رایگان)

## ۶. بعد از انتشار: چه چیزی را نگاه کنیم

با `GET /admin/events?days=30` (هدر `X-Admin-Token`):

| رویداد | چه می‌گوید |
|---|---|
| `onboarding_completed` | چند نفر شروع کردند |
| `scan` / `voice_log` / `log_food` | استفاده‌ی واقعی |
| `paywall_view` ← `purchase` | نرخ تبدیل |
| `retention_d1` / `d7` / `d30` | نگه‌داشت |

و `GET /admin/stats` برای هزینه‌ی مدل در هر اسکن. بر این اساس سهمیه‌ی رایگان (۳) و قیمت تنظیم شود (بخش ۱۴-۵ و ۱۴-۶).
