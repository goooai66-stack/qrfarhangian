# راه‌اندازی کالری‌لنز از صفر

سه قدم: سرور را بالا بیاور، در پنل مدیریت کلید هوش مصنوعی را وارد کن، آدرس سرور را در اپ بگذار.

---

## قدم ۱. سرور

**چه لازم داری**
- یک سرور لینوکسی (Ubuntu) با IP عمومی که از داخل ایران در دسترس باشد. یک گیگابایت رم کافی است.
- یک دامنه یا زیردامنه (مثلاً `api.example.ir`) که رکورد A آن به IP سرور اشاره کند.
- پورت‌های ۸۰ و ۴۴۳ باز باشند.
- Docker روی سرور نصب باشد.

**نصب (روی سرور)**

```bash
git clone https://github.com/goooai66-stack/qrfarhangian.git
cd qrfarhangian
git checkout ccr-c35a8f55-qscvd4
bash deploy/install.sh api.example.ir
```

اسکریپت این کارها را می‌کند:
- یک «کد راه‌اندازی مدیر» تصادفی می‌سازد و در `deploy/.env` نگه می‌دارد.
- سرور را در حالت امن (production) بالا می‌آورد.
- گواهی HTTPS را خودکار می‌گیرد.

در پایان سه چیز چاپ می‌شود. هر سه را یادداشت کن:

```
آدرس سرور برای اپ:   https://api.example.ir
پنل مدیریت:          https://api.example.ir/admin
کد راه‌اندازی مدیر:   ................
```

> کد راه‌اندازی را به کسی نده. با آن می‌شود رمز مدیر را ساخت.

## قدم ۲. پنل مدیریت

۱. آدرس پنل (`https://دامنه/admin`) را در مرورگر باز کن.
۲. **ساخت رمز مدیر** (فقط بار اول): کد راه‌اندازی را وارد کن و یک رمز حداقل ۱۰ نویسه‌ای برای خودت بساز. از این به بعد فقط با همین رمز وارد می‌شوی.
۳. در بخش **هوش مصنوعی**، از فهرست **«سرویس هوش مصنوعی»** سرویس خودت را انتخاب کن. فقط خانه‌های همان سرویس نشان داده می‌شود:

| سرویس | چه چیزی وارد می‌کنی |
|---|---|
| OpenRouter | کلید (`sk-or-…`) و نام مدل |
| OpenAI (ChatGPT) | کلید (`sk-…`) و نام مدل |
| Anthropic (Claude) | کلید (`sk-ant-…`) و نام مدل |
| Google Gemini، xAI، Mistral، Groq، Together | کلید و نام مدل |
| سرویس دیگر (مثل 9Router یا درگاه‌های داخلی) | آدرس API همان سرویس (از پنل خودش)، کلید و نام مدل |

   - مدل باید **ورودی تصویر** داشته باشد، وگرنه اسکن عکس کار نمی‌کند.
   - هر وقت سرویس را عوض می‌کنی، کلید همان سرویس را هم وارد کن. پنل اجازه نمی‌دهد کلید یک سرویس به سرویس دیگری فرستاده شود.
   - در هر لحظه یک سرویس فعال است و عوض کردنش بلافاصله برای همه‌ی کاربران اعمال می‌شود.

۴. **«ذخیره و اجرا برای همه»** را بزن. زیر دکمه فهرست چیزهایی که عوض شد نوشته می‌شود.
۵. **«آزمایش اتصال به مدل»** را بزن. اگر نوشت «مدل پاسخ درست داد»، کار تمام است. اگر خطا داد، کلید یا نام مدل اشتباه است.

**چیزهای دیگری که از پنل عوض می‌شود** (همه بلافاصله و برای همه‌ی کاربران، بدون ری‌استارت):

| بخش | چه چیزی |
|---|---|
| سهمیه | تعداد اسکن و ثبت صوتی رایگان هر کاربر در روز، حداکثر اسکن در دقیقه |
| هزینه | قیمت توکن مدل، تا هزینه‌ی دلاری هر روز در جدول «۱۴ روز اخیر» حساب شود |
| هوش مصنوعی | عوض کردن مدل یا ارائه‌دهنده، مهلت پاسخ |
| تغییر رمز | رمز مدیر (رمز قبلی و همه‌ی نشست‌ها باطل می‌شوند) |

**امنیت پنل**
- کلید API بعد از ذخیره دیگر نمایش داده نمی‌شود (فقط ۴ نویسه‌ی آخر).
- رمز مدیر به‌صورت هش ذخیره می‌شود؛ حتی با دسترسی به دیتابیس خوانده نمی‌شود.
- بعد از ۸ تلاش ورود در ۱۵ دقیقه، ورود از آن IP موقتاً بسته می‌شود.
- اگر رمز را فراموش کردی، روی سرور این را اجرا کن و دوباره با کد راه‌اندازی رمز بساز (تنظیمات پاک نمی‌شود):
  ```bash
  docker compose -f deploy/docker-compose.yml exec api python -m app.reset_admin
  ```

## قدم ۳. اپ

**فایل APK** از GitHub ساخته می‌شود: برگه‌ی **Actions** مخزن ← آخرین اجرای **Build APK** ← پایین صفحه، بخش **Artifacts**.

هر فروشگاه سه فایل دارد. روی گوشی‌های امروزی `app-arm64-v8a-…-release.apk` را نصب کن. `armeabi-v7a` برای گوشی‌های قدیمی ۳۲ بیتی است.

**وصل کردن اپ به سرور**: پروفایل ← «درباره، حریم خصوصی و داده‌ها» ← **آدرس سرور** ← آدرس قدم ۱ را وارد کن. اپ اول بررسی می‌کند که آن آدرس واقعاً سرور کالری‌لنز است، بعد ذخیره می‌کند.

**برای انتشار عمومی** بهتر است آدرس داخل خود APK باشد تا کاربر چیزی وارد نکند:
برگه‌ی Actions ← **Build APK** ← **Run workflow** ← آدرس سرور را در کادر `api_base_url` بنویس. در این حالت گزینه‌ی «آدرس سرور» در اپ دیده نمی‌شود.

## قبل از انتشار در فروشگاه

- [ ] **کلید امضا.** APK فعلی با کلید آزمایشی امضا شده و فروشگاه قبولش نمی‌کند. کلید را یک بار روی رایانه‌ی خودت بساز و چهار Secret را در GitHub بگذار (راهنما بالای فایل `.github/workflows/build-apk.yml`). کلید را در دو جای امن نگه دار؛ بدون آن دیگر نمی‌شود به‌روزرسانی داد.
- [ ] **اعداد کالری را بسنج.** پایگاه غذا (۱۵۸ غذا) با **تخمین** پر شده، نه با منبع تأییدشده، و اپ کنار همه‌شان «تقریبی» نشان می‌دهد. جدولش در `server/tools/build_foods.py` است. هر ردیفی را که با منبع یا ترازو سنجیدی اصلاح کن و اسکریپت را دوباره اجرا کن.
- [ ] **مدل را روی عکس واقعی بسنج**: `server/tools/eval_photos.py` روی حدود ۵۰ عکس غذا.
- [ ] روی یک گوشی ارزان تست کن (چک‌لیست در `docs/RELEASE.md`).
- [ ] آیکون نهایی، اسکرین‌شات‌ها و متن فروشگاه (پیش‌نویس در `docs/RELEASE.md`).
- [ ] صفحه‌ی `docs/privacy.html` را روی یک آدرس عمومی بگذار و لینکش را به فروشگاه بده.
